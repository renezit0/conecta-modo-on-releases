# Conecta Modo ON — versões

Aqui ficam só os instaladores do telão **Conecta Modo ON** (sem o código-fonte).

**Baixar a versão mais nova:**
https://github.com/renezit0/conecta-modo-on-releases/releases/latest/download/conecta-modo-on-win_x64.exe

Depois de aberto uma vez, o telão se atualiza sozinho: confere ao abrir e a cada 30 minutos,
e quando sai versão nova ele baixa, fecha e reabre já atualizado.
